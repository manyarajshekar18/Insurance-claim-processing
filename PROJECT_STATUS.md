# Insurance Claim Processing System

AI-powered insurance claim processing using Java, Spring Boot, React, MySQL and Gemini AI.

## Implemented Modules
- JWT authentication and role-based access
- Policy and claim management
- Document upload
- Gemini AI claim analysis
- Officer claim review
- Customer, Officer and Admin dashboards
